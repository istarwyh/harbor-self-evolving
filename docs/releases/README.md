## 后续版本沿用的格式

```text
docs/releases/vX.Y.Z/
  README.md             # 变更摘要、操作步骤、结果、边界、来源
  screenshots/          # 编号 + 场景名；真实截图
```

每版选择 4–8 张最能说明变化的图，不必重复所有页面。对 UI 变更优先记录选择、提交前、执行中、结果或恢复等关键状态；非 UI 变更附对应测试/日志/提交链接，不制造示意截图充当运行证据。存在真实的前后截图时才做前后对照。

每张说明记录日期、版本/提交或验收环境、操作过程、预期与实际结果，以及 synthetic / controlled-model / real-provider / public-release 等证据类型。历史原图与本次补截分开标明；一张静态截图不证明完整状态转换。公开前检查可读性、凭据、个人信息和业务私有内容，保留未完成项及非阻塞警告。

归档完成后，在对应 GitHub Release 放上图集入口和可下载的验证资料包。这里只是资料组织约定，不新增发布校验脚本、CI 门禁或人工审批，也不会自动运行模型、评测或发布。
