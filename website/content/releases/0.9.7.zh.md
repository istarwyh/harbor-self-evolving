发布于 2026-09-20。正式 source tag：[`v0.9.7`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.9.7)。

## 已交付 {#shipped}

- Candidate Context v3 在 Dashboard overview 与 Job detail 中有效；满足条件的 Job 可使用 Compare/Gate。
- Historical Context v2 按 protocol 显式识别，包括仅有 Context 的 pending Job。
- Setup 持久化完整安装身份；Settings 只复制可审阅的精确更新命令，绝不执行 registry 包。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.9.7。
- 双语产品与文档站覆盖 19 个工具、Skill、Adapter、评测概念、证据边界与 Roadmap。

## 验证 {#verification}

[0.9.7 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.9.7/README.md)记录自动化 Node/Python/package/site 检查、公开 package 身份与 release 附件。发布状态与证据状态分开报告。

## 限制 {#limits}

> [!WARNING]
> 0.9.7 未运行真实供应商模型、真实 Candidate/Historical Session 数据或付费 Harbor 评测；自动化测试结论不构成业务质量基线。

默认 Host 模式不是沙箱。Same-origin 是浏览器 CSRF 防线，不是 caller authentication。Gate 对固定输入确定，但不等于部署。
