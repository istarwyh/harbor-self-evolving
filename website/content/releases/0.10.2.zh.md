发布于 2026-09-27。正式 source tag：[`v0.10.2`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.10.2)。

## 已修复 {#fixed}

- 每个 Harbor client-plugin 生命周期拥有独立样式标签，旧的重复实例或热重载实例销毁时不会再移除当前 Workbench 样式。
- Job 状态文字固定在卡片右上角，不再随标题区域高度拉伸。
- 移除状态外层背景圈，同时保留完成、运行、关注和失败的颜色与符号。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.10.2。

## 验证 {#verification}

[0.10.2 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.10.2/README.md)记录针对性生命周期/布局检查与协调 package 发布证据。

## 限制 {#limits}

> [!WARNING]
> 针对性源码和 bundle 检查不能替代完整的跨平台视觉验收。本次补丁不改变评测行为，因此没有运行付费或真实 Provider Candidate Job。

默认 Host 模式仍不受限、不是沙箱。Historical 结果永远不能成为 Promotion Gate 证据，Job seal 仍是内容完整性收据而不是外部签名。
