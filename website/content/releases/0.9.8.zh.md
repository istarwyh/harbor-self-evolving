发布于 2026-09-21。正式 source tag：[`v0.9.8`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.9.8)。

## 已交付 {#shipped}

- Host 命令转换保留已经解析到 Trial Host 目录的路径。
- Historical Session Observation 与 Candidate 命令不会再次添加 Host Root 前缀。
- HostEnvironment 集成测试执行 SessionObservationAgent 的上传、Digest 校验与 Artifact 写入完整路径。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.9.8。

## 验证 {#verification}

[0.9.8 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.9.8/README.md)记录专项与完整自动化检查。发布状态与证据状态分开报告。

## 限制 {#limits}

> [!WARNING]
> 源码测试使用不调用模型的合成 Session Observation。仍需从正式包启动新的 Historical Job，以验证 Adapter、Renderer 与 Judge 完整路径。

默认 Host 模式不是沙箱。本修复不修改 Evaluator 标准、评分、Gate 行为或数据脱敏。
