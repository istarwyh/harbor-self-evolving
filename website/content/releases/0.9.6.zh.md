发布于 2026-09-19。正式 source tag：[`v0.9.6`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.9.6)。

## 已交付 {#shipped}

- Host 成为默认执行环境；Docker 保持显式 opt-in。
- Candidate Context 记录执行环境，因此 Host 与 Docker 不会静默可比。
- Plugin、Skill 与 Python Adapter package 身份对齐为 0.9.6。
- 普通 registry setup 继续作为支持的安装路径。

## 验证 {#verification}

归档记录自动 Node/Python/package check 与公开 release 身份。证据类型与业务验收保持分离。

## 限制 {#limits}

> [!WARNING]
> 0.9.6 未运行真实供应商模型、真实 Candidate/Historical Session 数据或付费 Harbor 评测；自动化测试结论不构成业务质量基线。

默认 Host 模式不是沙箱。Candidate Context v3 Web Compare/Gate 也存在[已记录的 0.9.6 合约问题](https://istarwyh.github.io/harbor-self-evolving/zh/product/dsh-plugin/#limits)。

网站与 GitHub Pages 部署只是文档交付，不会反向改变 0.9.6 package 或证据状态。
