发布于 2026-09-26。正式 source tag：[`v0.10.0`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.10.0)。

## 已交付 {#shipped}

- 正式 Candidate Experiment 只通过私有 Dataset 中的严格 Adapter 执行 exact `harbor-dsh-evaluator/v2` bundle；Dataset verifier 与 v1 fallback 不能成为分数权威。
- 可信 Evaluation Report、内容寻址 Job bundle、跨产物 Evaluator 身份、score suppression 与执行失败处理，阻止无效证据进入质量结论。
- repeat-aware Experiment、paired uncertainty、不可覆盖 Promotion report、exact Policy snapshot 和更严格的 Docker/环境 invariant，让 governed comparison 可审计。
- Historical diagnosis、Candidate-bound business observation、独立 Ground Truth meta-evaluation 与人工确认 badcase draft 保持各自证据边界。
- diagnostic、experiment 与 governed 产品模式只展示当前证据级别允许的控制面。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.10.0，两个 package 均包含 34 个公共 Schema。

## 验证 {#verification}

[0.10.0 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.10.0/README.md)记录 632 个 Node tests、378 个 Python tests、package/Schema 检查与 Deep Research fixture。发布状态与证据状态分开报告。

## 限制 {#limits}

> [!WARNING]
> 源码自动化验证不等于真实 Provider 业务质量证明。开发环境未完成授权 GUI 人工点击、付费/真实 Provider Candidate Job 和本地 wheel 构建；公开 package workflow 与 registry 另行核对。

默认 Host 模式不受限、不是沙箱。Historical 结果永远不能成为 Promotion Gate 证据，Job seal 只是内容完整性收据，不是外部签名。
