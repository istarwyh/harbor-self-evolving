发布于 2026-09-26。正式 source tag：[`v0.10.1`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.10.1)。

## 已交付 {#shipped}

- 正式 Candidate Experiment 只通过私有 Dataset 严格 Adapter 执行 exact `harbor-dsh-evaluator/v2` bundle；Dataset verifier 与 v1 fallback 不能成为分数权威。
- 可信 Evaluation Report、内容寻址 Job bundle、跨产物 Evaluator 身份、score suppression 与执行失败处理，阻止无效证据进入质量结论。
- repeat-aware Experiment、paired uncertainty、不可覆盖 Promotion report、exact Policy snapshot 和更严格的 Docker/环境 invariant，让 governed comparison 可审计。
- Historical diagnosis、Candidate-bound business observation、独立 Ground Truth meta-evaluation 与人工确认 badcase draft 保持各自证据边界。
- diagnostic、experiment 与 governed 产品模式只展示当前证据级别允许的控制面。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.10.1，两个 package 均包含 34 个公共 Schema。

## 发布修复 {#repair}

0.10.0 已发布到 npm，但 clean Linux tag/PyPI workflow 在构建 Python artifact 前暴露两项 release-test portability 问题。公开 tag 和 package 版本没有移动或覆盖。0.10.1 保持相同 runtime 行为，修复 test-helper 导入并使用仍有界的 shared-runner 响应预算，正式取代 0.10.0。

## 验证 {#verification}

[0.10.1 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.10.1/README.md)记录本地自动化证据、0.10.0 失败发布证据与 0.10.1 协调发布状态。

## 限制 {#limits}

> [!WARNING]
> 源码自动化验证不等于真实 Provider 业务质量证明。未执行授权 GUI 人工点击和付费/真实 Provider Candidate Job。

默认 Host 模式不受限、不是沙箱。Historical 结果永远不能成为 Promotion Gate 证据，Job seal 只是内容完整性收据，不是外部签名。
