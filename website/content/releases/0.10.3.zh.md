目标发布日期：2026-09-27。计划 source tag：[`v0.10.3`](https://github.com/istarwyh/harbor-self-evolving/releases/tag/v0.10.3)。

## 变化

- 目录读取被拒绝时返回稳定的 `HARBOR_PROJECT_ROOT_ACCESS_DENIED`，不暴露本地路径。
- Workbench 明确说明这不是网络问题，给出 macOS 权限恢复和迁移项目目录的步骤；技术详情默认折叠，并可复制恢复说明。
- 分类仅覆盖目录读取，普通文件操作的 `EACCES` 不会被误标。
- 即使宿主使用 `NODE_ENV=production`，源码开发 setup 也会显式安装锁定 dev dependencies。
- Plugin、Skill 与 Python Adapter 身份对齐为 0.10.3。

## 证据边界

[0.10.3 归档](https://github.com/istarwyh/harbor-self-evolving/blob/main/docs/releases/v0.10.3/README.md)记录针对性 service/client/setup 检查、生成后的 client bundle 与源码 setup；公开 package 证据在发布后补录。它不代表完整跨平台 TCC/ACL 覆盖，也未修复桌面宿主的签名和权限声明。
