要求用户先装 Docker 才能诊断 Agent，会制造摩擦；假装直接执行具有隔离性，则会制造风险。0.9.6 选择 Host 作为默认，并精确说明边界。

Host 模式以当前用户权限与环境运行，不提供容器隔离、用户切换、网络策略或 CPU/内存限制。需要这类边界时，Docker 仍是显式 opt-in。

执行环境成为 Context 身份的一部分，Host 结果不会静默与 Docker 比较。只要 runtime 差异持续可见，降低门槛不必牺牲证据质量。
