Choose the path that matches your question:

- [Install and start](https://istarwyh.github.io/harbor-self-evolving/docs/start/) — get the Plugin, Adapter and Skill into the selected DSH profile.
- [Historical diagnosis](https://istarwyh.github.io/harbor-self-evolving/docs/workflows/historical/) — learn from recent completed Sessions without calling them promotion evidence.
- [Candidate evaluation](https://istarwyh.github.io/harbor-self-evolving/docs/workflows/candidate/) — freeze identities, run a comparable regression and apply policy.
- [Plugin Workbench](https://istarwyh.github.io/harbor-self-evolving/docs/plugin/) — understand Context, Evidence, Artifacts and reviewed actions.
- [Concepts](https://istarwyh.github.io/harbor-self-evolving/docs/concepts/) — learn why valid score, raw reward and coverage are not interchangeable.
- [Architecture](https://istarwyh.github.io/harbor-self-evolving/docs/architecture/) — inspect protocols, execution environments and trust boundaries.
- [19-tool reference](https://istarwyh.github.io/harbor-self-evolving/docs/reference/tools/) — look up every Agent tool and approval boundary.
- [Security](https://istarwyh.github.io/harbor-self-evolving/docs/security/) — read the limits before running untrusted Tasks.

> [!IMPORTANT]
> Version baseline: **Harbor Self-Evolving 0.9.6 (Beta)**, compatible with **Harbor `>=0.21,<0.22`**. Development-preview behavior from an untagged checkout is labeled separately.
